# ADR-0003: Offline-first и синхронизация last-write-wins

**Статус:** принято

**Решение.** Источником правды на устройстве служит локальная SQLite. Сервер принимает пачки изменений и разрешает конфликты по `updated_at` клиента (LWW), удаления хранит как tombstone, отдаёт дельты по `server_updated_at > since`. Прогресс по главе монотонен по признаку `completed`. Сессии истории идемпотентны (UUID генерирует клиент).

**Почему не CRDT.** Пользовательские данные почти не конфликтуют: один человек редко читает одну главу на двух устройствах одновременно. LWW намного проще, и его достаточно.
