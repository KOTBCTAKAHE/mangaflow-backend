# ADR-0004: Подписанный прокси изображений

**Решение.** Все обложки и страницы отдаются через `/api/v1/images/{token}`, где token = base64(JSON{source, url, exp}) + HMAC-SHA256. Сервер скачивает картинку с заголовками адаптера, кэширует её на диске (LRU-чистка), по `?w=` умеет уменьшать до WebP и отвечает с `Cache-Control: public, max-age=604800, immutable`.

**Почему так.** CDN источников требуют Referer и блокируют hot-link. Подпись не даёт использовать сервер как открытый прокси. Неизменяемые URL кэшируются в nginx или любом CDN.
