# ADR-0001: Перенос источников Mangayomi на Python

**Статус:** принято

**Контекст.** `redcatpet/mangayomi-ru-sources` — это JS-расширения, которые исполняются только в рантайме Mangayomi (`MProvider`, `Client`, `Document`). Готового API у репозитория нет. Backend по ТЗ пишется на Python/FastAPI.

**Решение.** Логика 9 манга-источников перенесена на Python в пакет `mangaflow_sources` с единым интерфейсом `SourceAdapter`, с сохранением атрибуции (Apache-2.0).

**Последствия.** Один язык, типизированные модели, тесты на фикстурах, контроль таймаутов, повторов и лимитов. Изменения у автора оригинала переносятся вручную; публичные id — это base64url от исходных ссылок, поэтому формат ссылок адаптера можно менять без миграции данных, если сама ссылка на сайт остаётся прежней.
