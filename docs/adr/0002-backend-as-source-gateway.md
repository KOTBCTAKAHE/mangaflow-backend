# ADR-0002: Backend как единый шлюз к источникам

**Статус:** принято

**Контекст.** Можно было бы парсить источники прямо в приложении (как это делает Mangayomi), но тогда кэша нет вообще, каждый клиент сам упирается в гео-блоки, а исправления парсеров требуют обновлять приложение.

**Решение.** Мобильное приложение ходит к источникам только через backend. Backend кэширует ответы, подписывает ссылки на изображения и проксирует их с нужными Referer. Для сайтов с гео-блоком задаётся `SOURCES_PROXY`.

**Последствия.** Парсеры исправляются без релиза приложения, кэш общий для всех пользователей, а nginx/CDN может кэшировать картинки. Цена — нагрузка и трафик на сервере (смягчаются кэшем на диске и nginx `proxy_cache`). Загруженные главы при этом читаются полностью офлайн.
